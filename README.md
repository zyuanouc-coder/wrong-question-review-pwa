# 拾题 · 错题复习 PWA

独立的七科错题本：政治理论、常识判断、言语理解、判断推理、数量关系、资料分析、公基。

## 使用

```sh
npm run preview
```

打开 http://127.0.0.1:4180 。iPhone 使用 Safari 访问部署地址，分享 → 添加到主屏幕。第一次联网打开、在设置中看到“离线资源已就绪”后可离线使用。

正式题库初始为空。首页可主动导入 3 道自编示例体验，示例明确标记，不冒充用户的真实错题。
体验完成后可在“设置 → 移除示例题及示例复习记录”中清除示例，真实题目会保留。

## 题库整理流程

用户提供截图、PDF、文字及可选的官方答案、我的错误答案、来源、做题日期。整理者逐题核对题干和选项，补写解析、记忆要点、科目与专题。存在疑点的题用 `pending` 标记，不进入复习。

每一批交付 `question-bank.json` 和便于人工检查的 `question-bank-preview.md`。核对后将完整累计题库写入 `data/question-bank.json`，递增 `revision` 并发布 GitHub Pages。手机打开、刷新、恢复前台或联网时自动下载并合并，无需手动导入。进行中的复习或编辑结束后才应用更新。

仍可在“题库 → 导入题库”中手动导入未公开的私人材料。

具体格式见 [INPUT_FORMAT.md](INPUT_FORMAT.md) 与 [示例](data/example-bank.json)。

## 复习规则

- 四种题型：单选、多选、判断、问答。前三种自动判分，多选需完全匹配；问答自评。
- 不会/答错：10 分钟后；模糊：1 天后并降低一级；答对：1、3、7、14、30、60、120 天逐级推进；熟练：提前一级。
- 选择题实际答错时，不能用“答对/熟练”推进。
- 到期题优先，其后按每日上限加入新题。默认每天最多 20 道新题、每组 20 题、慢题阈值 60 秒，设置可改。
- 额外错题/慢题/专题练习同样会重新安排日期。不会的题在 10 分钟后进入下次开始的队列。
- 答案显示前单独计时，切换后台暂停计时。解析阅读时间不计入。
- 固定间隔算法，非 FSRS，不推断个人遗忘曲线，不发送后台通知。

## 数据与更新

- GitHub 发布题库为公开内容；手机本地题库、个人笔记、每次作答和复习进度使用 `wrong-question-review-v1` 存储，应用不会上传这些本机数据。
- 不上传导入内容，无账号、无跨设备同步。浏览器清理数据会丢失本机记录，请定期导出完整备份。
- 相同 ID 更新题目、保留进度和个人笔记。题干/选项/答案发生更改时重新安排复习，保留旧历史。
- 同科目、相同题干与选项但不同 ID 的重复题跳过；答案冲突则整批拒绝，先核对后导入。
- 完整备份恢复会替换本机数据，界面显示数量并提供先导出当前数据的按钮。
- 网站初始发布空题库和明确标记的自编示例；用户提供并要求发布的后续题库通过 `data/question-bank.json` 分发。发布的题目、解析及写入题库的字段会公开，私人材料应采用本机导入。
- 发布批次单调递增；相同批次不重复写入，旧批次缓存不会覆盖已合并的新批次。同批次修改内容会拒绝自动合并，需递增 revision。空题库不会删除本机题目。
- 应用升级需同步所有模块/CSS查询参数与Service Worker缓存版本，保持存储键不变。

## 验证

`npm run check` 验证核心调度、计时记录、答案判定、幂等导入、冲突拒绝、进度保留、备份、并发写入、PWA资源与图标。

浏览器端另验收导入、单多选与问答、笔记、到期队列、统计、完整备份恢复、手机320×568/390×844布局与离线重载。

运行 `tests/ui.mjs` 需要安装 Playwright 与 Chrome；可以通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径。`QA_URL` 默认本机预览地址，也可指向已部署页面。测试使用独立临时浏览器上下文，数据不影响用户。

`tests/sync-ui.mjs` 启动临时发布服务器，验证自动合并、刷新幂等、在线触发、答题时延后应用、旧缓存不回退与离线保留本机数据。
